# home-security-monitoring-lab

This is my personal project.

##Environment##
- Host: MacBook - Apple Silicon
- Target: Windows 10 


Phase 1 — Establish your lab. Prepare Windows, document your hardware and software, and establish controlled connectivity between the two computers.


Phase 2 — Understand the network. Identify IP addresses, map your own test machine, capture traffic, and understand normal network behaviour.


Phase 3 — Collect security logs. Capture Windows authentication, process, and system events, and learn how to investigate them.


Phase 4 — Build a SIEM. Ingest logs into Splunk or another security monitoring platform and create useful searches, dashboards, and alerts.


Phase 5 — Simulate and detect. Generate controlled security events, test your detections, and investigate what the monitoring system records.


Phase 6 — Harden and report. Fix the weaknesses you find, repeat your tests, measure the improvement, and publish a professional portfolio report.


Phase 7 — Extend into cloud security. Reproduce selected detection and identity-security concepts in an AWS or Azure lab, then compare cloud telemetry with your local lab.
